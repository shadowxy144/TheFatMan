# Network Management & Diagnostics Tool (Fatman)

This repository contains a Bash-based menu interface and utility script designed for local network analysis, device monitoring, and administrative network operations.

## Features

* **Automated Setup:** Easily install and update system dependencies (`bettercap`, `python3`).
* **Interactive Menu:** Simple terminal menu interface for quick navigation.
* **Integrated Documentation:** Built-in local HTTP server to view documentation offline via a web browser.
* **Network Operations:** Interface options for monitoring network traffic and administrative testing.

## Prerequisites

* **Operating System:** Linux (Debian/Ubuntu/Kali Linux recommended)
* **Privileges:** Sudo / Root access required for package management and network utilities
* **Packages:** `apt`, `python3`, `bettercap`, `xdg-utils`
